# jBoids
boids in java swing/awt

made as an interactive eyecatcher for college involvement fair to advertise our ACM chapter

left click to create a boid<br>
right click to make all boids head towards where you clicked<br>
press w to create white boids, b for blue boids, and y for yellow boids<br>
boids on different teams will avoid colliding with each other but will not maintain cohesion or alignment
